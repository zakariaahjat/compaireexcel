Aide — Comment utiliser le comparateur

Tout ce qu'il faut savoir pour comparer deux fichiers Excel ou CSV.

1Comment ça marche
1Chargez votre Fichier 1 dans la zone de gauche, puis le Fichier 2 à droite — glisser-déposer ou cliquer.
2Les colonnes identifiant, libellé et valeur sont détectées automatiquement. Si besoin, cliquez sur « Ajuster les colonnes… » pour corriger le choix.
3Le tableau compare les deux fichiers : lignes communes, uniquement fichier 1, uniquement fichier 2, écarts de valeur et le meilleur côté.
4Filtrez avec les pastilles (Tout / Écarts / Égaux…), recherchez avec la touche /, triez en cliquant sur les en-têtes de colonnes.
5Exportez : Copier dans le presse-papiers, Imprimer / PDF, CSV, ou Excel coloré avec une feuille de résumé.
2Comment préparer votre Excel

Idéalement : une ligne d'en-tête en haut, puis une ligne par article. Une ligne de titre (bannière) au-dessus n'est pas un problème : elle est ignorée automatiquement. Exemple :

RéférenceDésignationStock DisponiblePrix Unitaire HT
GPU-RTX4060GeForce RTX 4060 8GB1481,299.00 DH
CPU-INTEL-13400FIntel Core i5-13400F284189.00 DH

Dans cet exemple, la colonne Stock Disponible est comparée par défaut. Pour comparer les Prix à la place, ouvrez « Ajuster les colonnes… », choisissez la colonne Prix Unitaire HT comme valeur, puis le type « Prix » — le symbole « DH » est détecté automatiquement.

En-têtes reconnus automatiquement :

Identifiant : code, référence, ref, sku, codebarre, ean, identifiant… Libellé : désignation, nom, libellé, description, produit… Valeur stock : stock, quantité, qté, disponible, solde… Valeur prix : prix, prix unitaire HT, tarif, coût…
3Bon à savoir
Nombres : les virgules décimales (12,50) et les séparateurs de milliers (1 234,56) sont lus automatiquement.
Devises : si l'en-tête contient « DH », « $ » ou « € » (ex. « Prix Unitaire HT », « Prix DH »), le symbole est détecté automatiquement.
Comparaison : les deux fichiers sont comparés par code produit — le même identifiant doit exister dans les deux fichiers.
Une seule valeur : une seule colonne « valeur » est comparée à la fois. Si votre fichier contient Stock ET Prix, la colonne Stock est choisie par défaut. Ouvrez « Ajuster les colonnes… » pour comparer une autre colonne.

Exporter en Excel

Choisissez la portée de l'export. Le fichier contient les couleurs (vert / jaune), la colonne « Meilleur côté » et une feuille de résumé.

Configurer les colonnes

L'en-tête n'a pas été reconnu automatiquement. Sélectionnez la ligne d'en-tête, puis la colonne identifiant, le libellé et la valeur à comparer. Les colonnes correspondent au .

Astuce : si la ligne d'en-tête proposée est une ligne de titre (« FICHIER DE STOCK… »), choisissez la ligne suivante.

Choisissez n'importe quelle colonne numérique : quantité, stock, prix, poids…

Le symbole est détecté automatiquement si l'en-tête contient DH, $, €, dirham, dollar… Sinon choisissez-le manuellement.
